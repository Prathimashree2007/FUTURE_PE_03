# SEO Content Cluster Generator

## Project Overview

This project demonstrates a reusable AI prompt system for generating SEO-optimized blogs and content clusters for business websites.

The system is designed to work like a professional SEO content strategy workflow.

It focuses on:

- Keyword research
- Search intent
- Pillar content
- Supporting content
- Internal linking
- Local SEO
- Topical authority
- Lead generation

---

## Selected Business

**Business Type:** Dental Clinic

**Location:** Bangalore, Karnataka, India

**Target Audience:** Adults, parents, students, and working professionals looking for dental care.

**Business Goal:** Increase organic traffic, build trust and authority, and generate appointment enquiries.
